# InkSoul / 墨魂 - 小白使用教程

欢迎使用 InkSoul / 墨魂！本教程将帮助你快速上手，无需任何技术背景也能轻松使用。

## 📦 第一步：下载与安装

### Windows 用户

1. **下载压缩包**
   - 从发布页面下载 `AI酒馆-Windows.zip`
   - 或直接下载项目文件夹

2. **解压文件**
   - 右键点击压缩包，选择"解压到..."
   - 建议解压到桌面或 D 盘根目录
   - 解压后文件夹名应为 `自建酒馆ai`

3. **检查 Node.js**
   - 双击运行 `启动控制面板.bat`
   - 如果提示"未检测到 Node.js"，请访问 https://nodejs.org/ 下载并安装
   - 安装时选择"Next"即可，无需修改默认选项

### macOS 用户

1. **下载压缩包**
   - 从发布页面下载 `AI酒馆-macOS.zip`
   - 或直接下载项目文件夹

2. **解压文件**
   - 双击压缩包自动解压
   - 将解压后的文件夹移动到"应用程序"或桌面

3. **检查 Node.js**
   - 打开终端，输入 `node -v` 检查是否已安装
   - 如果未安装，访问 https://nodejs.org/ 下载 macOS 版本
   - 安装后重启终端再次检查

### Linux 用户

1. **下载压缩包**
   - 从发布页面下载 `AI酒馆-Linux.zip`
   - 或直接下载项目文件夹

2. **解压文件**
   ```bash
   unzip AI酒馆-Linux.zip
   cd 自建酒馆ai
   ```

3. **检查 Node.js**
   ```bash
   node -v
   ```
   - 如果未安装，使用包管理器安装：
   - Ubuntu/Debian: `sudo apt install nodejs npm`
   - Fedora: `sudo dnf install nodejs npm`
   - Arch: `sudo pacman -S nodejs npm`

## 🔑 第二步：首次使用 - 提取小说数据

### 为什么需要提取小说数据？

AI 酒馆需要从小说文件中提取角色、事件、关系、世界书等数据，才能生成准确的故事内容。这个过程只需要执行一次（除非小说更新）。

### 多小说支持

AI 酒馆支持多本小说的数据隔离管理。每本小说的数据（角色、事件、关系、世界书等）都存储在独立的目录中，互不干扰。

**功能特性：**
- 可以添加多本小说
- 每本小说的数据相互独立
- 可以在小说之间切换
- 删除小说不会影响其他小说的数据

### 提取步骤

1. **启动控制面板**
   - Windows: 双击 `启动控制面板.bat`
   - macOS/Linux: 双击 `启动控制面板.sh` 或在终端运行 `./启动控制面板.sh`

2. **打开"小说初始化"标签页**
   - 浏览器会自动打开控制面板（http://localhost:3002）
   - 点击顶部的"📖 小说初始化"标签页

3. **添加小说**
   - 点击"添加小说"按钮
   - 输入小说文件路径（相对路径或绝对路径）
   - 输入小说ID（可选，留空自动从文件名生成）
   - 小说ID示例：`gu_zhen_ren`（从文件名 `Gu Zhen Ren.txt` 生成）

4. **选择小说**
   - 在"选择小说"下拉框中选择要操作的小说
   - 激活的小说会用于后续的数据提取和游戏

5. **开始提取**
   - 点击"开始提取小说"按钮
   - 等待提取完成（根据小说大小，可能需要 10-30 分钟）
   - 可以在"提取日志"区域查看实时进度

6. **提取完成**
   - 提取完成后，状态会显示"已提取"
   - 显示提取统计：角色数、事件数、世界书条目数
   - 现在可以开始使用故事功能

```
[截图位置：小说初始化标签页]
显示小说选择器、添加/删除按钮、状态卡片、开始提取按钮和提取日志区域
```

### 提取失败怎么办？

- **小说文件不存在**：确保小说文件路径正确
- **提取中断**：可以点击"停止提取"，然后重新开始
- **其他错误**：查看提取日志中的错误信息，或查看常见问题章节

### 小说管理

**添加小说：**
- 点击"添加小说"按钮
- 输入小说文件路径
- 小说文件可以是相对路径（如 `./novels/小说.txt`）或绝对路径

**切换小说：**
- 在"选择小说"下拉框中选择要激活的小说
- 切换后，提取和游戏功能会使用该小说的数据

**删除小说：**
- 选择要删除的小说
- 点击"删除小说"按钮
- 确认删除操作
- 注意：删除小说会同时删除该小说的所有提取数据，无法恢复

## � 第七步：生成故事框架（可选）

### 什么是故事框架？

故事框架是根据小说数据生成的故事结构蓝图，包含：
- 主角设定（背景、性格、目标等）
- 章节划分（起点到终点的章节范围）
- 事件时间轴（原著中的关键事件）
- 锚点设定（必须遵守的原著情节）
- 分支点设定（可能出现分支的章节）

### 生成步骤

1. **打开框架生成标签页**
   - 在控制面板点击"📚 故事框架"标签页

2. **填写主角信息**
   - 主角名称：如"远坊"
   - 主角类型：原创/原著
   - 起始位置：如"中州中型门派"
   - 起始境界：如"一转初阶"
   - 玩家影响程度：低/中/高

3. **展开主角详细档案（可选）**
   - 点击"展开/收起编辑"按钮
   - 填写更详细的主角设定
   - 留空则使用默认值

4. **生成框架**
   - 点击"生成故事框架"按钮
   - 等待生成完成（约10-30秒）
   - 查看生成的统计数据：事件数、锚点数、分支点

5. **查看已有框架**
   - 点击"查看已有框架"按钮
   - 查看所有已生成的框架列表
   - 点击"查看"查看框架详情
   - 点击"删除"删除不需要的框架

### 从框架创建故事

1. 在框架列表中找到要使用的框架
2. 点击"创建故事"按钮
3. 系统会自动创建新故事并关联该框架
4. 故事将使用框架中的主角设定和章节规划

### 框架管理

- **删除框架**：点击框架列表中的"删除"按钮
- **查看框架**：点击"查看"按钮查看框架详细内容
- **重新生成**：可以重新生成同一主角的框架以更新设定

## ❓ 常见问题

### Q1: 防火墙拦截怎么办？

**Windows:**
1. 首次启动时，Windows 会弹出防火墙提示
2. 选择"允许访问"或"公共网络"和"专用网络"
3. 如果没有弹出，进入"Windows Defender 防火墙"
4. 点击"允许应用通过防火墙"
5. 找到 Node.js，勾选"专用网络"和"公共网络"

**macOS:**
1. 系统偏好设置 > 安全性与隐私 > 防火墙
2. 点击"防火墙选项"
3. 找到 Node.js，允许其连接

**Linux:**
```bash
sudo ufw allow 3000
sudo ufw allow 3002
```

### Q2: 故事加载不出来怎么办？

**检查步骤：**
1. 确认服务器状态为"运行中"
2. 确认已执行小说数据提取
3. 刷新浏览器页面（F5）
4. 检查浏览器控制台是否有错误（F12）
5. 确认 API Key 已正确配置

**解决方案：**
- 如果 API Key 错误，重新配置
- 如果服务器未运行，重新启动
- 如果未提取小说数据，先执行提取
- 如果端口被占用，修改端口配置

### Q3: 如何备份存档？

存档文件位于 `data/` 目录：
- `long_term_memory.json` - 长期记忆
- `extraction_progress.json` - 提取进度
- 其他 JSON 文件

**备份方法：**
1. 关闭服务器
2. 复制整个 `data/` 文件夹
3. 粘贴到其他位置作为备份

### Q4: 如何更新到新版本？

1. 下载新版本压缩包
2. 备份你的 `data/` 文件夹
3. 解压新版本覆盖旧文件（保留 `data/`）
4. 启动新版本

### Q5: 如何修改故事生成参数？

在故事界面中：
1. 点击右上角"设置"
2. 调整"玩家影响程度"（低/中/高）
3. 调整"上下文策略"（平衡/最大上下文/稳定）
4. 保存设置

### Q6: 如何清理记忆？

在控制面板中：
1. 暂不支持直接清理
2. 可以删除 `data/long_term_memory.json` 文件
3. 重启服务器后会重新生成

### Q7: 提取小说数据需要多长时间？

根据小说大小：
- 10MB 小说：约 10-20 分钟
- 20MB 小说：约 20-40 分钟
- 50MB 小说：约 40-60 分钟

提取过程在后台运行，你可以关闭浏览器，提取会继续进行。

### Q8: 为什么角色战力提升不明显？

**原因说明：**

1. **章节分布设计**
   - 前期（结束点10%-16%浮动）：打基础、积累资源、了解环境，战力提升缓慢
   - 中期（结束点55%-65%浮动）：开始快速成长
   - 后期（结束点75%-85%浮动）：战力大幅提升
   - 终期（85%-100%）：达到巅峰

   例如：300章的故事中，80章占比约26.7%，通常属于中期阶段，战力提升会逐渐加快。每次生成框架时，阶段结束点会在指定范围内随机浮动，让故事更加多样化。

2. **原著设定遵循**
   系统基于原著事件生成，如果原著前期战力提升缓慢，生成的故事会反映这一点，确保符合原著设定。

3. **玩家影响程度**
   - 低影响：主角对剧情干预少，战力提升较慢
   - 中影响：主角适度影响剧情
   - 高影响：主角对剧情影响大，战力提升更快

4. **AI生成逻辑**
   AI根据剧情自然发展，不会强制战力跳跃，确保合理性和逻辑性。

**解决方法：**

1. **调整玩家影响程度**
   - 在故事界面点击右上角"设置"
   - 将"玩家影响程度"调整为"高"
   - 保存设置后重新开始故事

2. **重新生成故事框架**
   - 在控制面板的"故事框架生成"部分
   - 设置更高的起点境界（如二转初阶而非一转）
   - 重新生成框架后创建新故事

3. **手动推动剧情**
   - 在故事中做出更多主动选择
   - 选择与修炼、战斗、资源获取相关的选项
   - 主动寻求提升实力的机会

4. **耐心等待**
   - 到达中期（30%进度）后战力提升会明显加快
   - 这是正常的故事节奏，不是bug
