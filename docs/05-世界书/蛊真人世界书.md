# 蛊真人世界书

## 一、修行体系

### 蛊师等级
- **一转到九转**：蛊师的基本修行等级，每一转代表一个境界层次
- **蛊仙**：突破九转后成为蛊仙，拥有仙窍福地，可使用仙蛊和仙道杀招
- **八转蛊仙**：顶级强者，如百足天君、凤九歌、武独秀等
- **九转尊者**：传说中的最高境界，如巨阳仙尊、红莲魔尊、盗天魔尊等

### 资质等级
- **甲等资质**：最高资质
- **乙等资质**：优秀资质
- **丙等资质**：普通资质
- **丁等资质**：较差资质
- **戊等资质**：最差资质
- **十绝天资**：极其罕见的顶级资质

### 能量体系
- **真元**：凡人蛊师的能量
- **仙元**：蛊仙的能量，分为不同种类（如青提仙元、红枣仙元）
- **元石**：通用货币，蕴含天地元气
- **仙元石**：更高级的货币，100块仙元石 = 1万青提仙元 = 100红枣仙元

### 道痕系统
蛊仙修行会在身上积累道痕，道痕越多实力越强。主要道痕包括：
- **力道**：增强力量
- **智道**：增强智慧，可推算、炼蛊
- **炎道**：火焰相关
- **飞行道**：飞行能力
- **魂道**：灵魂相关
- **偷道**：偷盗、隐匿
- **音道**：声音相关
- **律道**：规则、律令
- **奴道**：控制奴役
- **变化道**：变化形态
- **剑道**：剑术相关
- **阵道**：布置蛊阵
- **运道**：运气、命运
- **宙道**：时间相关
- **土道**：土石相关
- **水道**：水流相关
- **宇道**：空间相关
- **暗道**：黑暗、隐匿
- **血道**：血液相关，多为魔道
- **光道**：光芒相关
- **木道**：植物相关
- **金道**：金属相关
- **石道**：岩石相关

### 灾劫系统
- **人劫**：其他蛊仙的攻击
- **天劫**：天地降下的灾劫
- **地劫**：大地相关的灾劫
- 灾劫的起源是天道，天道损有余而补不足，破坏平衡的存在会遭受灾劫
