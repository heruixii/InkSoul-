# InkSoul / 墨魂

一个本地运行的 Web 端 AI 角色扮演与故事生成工具，支持基于小说数据创建自定义主角，生成互动式故事体验。

## 项目简介

InkSoul / 墨魂 是一个创新的 AI 角色扮演平台，结合了传统角色扮演游戏元素与现代 AI 技术。用户可以：

- 从小说文本中提取角色、事件、关系和世界设定
- 创建自定义主角，设定背景、性格、目标和起始位置
- 生成基于小说原著的故事框架，确保剧情走向符合原著设定
- 与 AI 驱动的角色进行互动，通过选择影响故事发展
- 解锁角色的隐藏经历和秘密，探索深层剧情

## 核心功能

### 📚 小说数据提取
- 支持多本小说的数据隔离管理
- 自动提取角色、事件、关系、世界书
- 生成时间轴和锚点系统，确保剧情连贯性
- **通用化设计**：支持任意小说，不再局限于特定作品
- **智能文件查找**：输入目录即可自动查找小说文件
- **性能优化**：并行处理章节，提取速度提升4-5倍
- **分段提取**：将长章节分成600字符片段，降低JSON解析错误
- **JSON自动修复**：自动修复格式错误的JSON，提高提取成功率
- **失败重试**：每段最多重试3次，确保数据完整性
- **定期保存**：每50章同步保存到文件，避免数据丢失
- **重试失败章节**：自动检测并重试失败的章节
- **手动指定重试**：支持指定章节范围进行重试
- **自动检测缺失**：自动识别缺失的章节并补充提取
- **智能锚点生成**：AI自动生成原著锚点，支持重要性评分和分层管理
  - 并发处理：批次大小10，速度提升5-10倍
  - 智能采样：每章最多5个事件
  - 缓存机制：避免重复API调用，提升效率
  - 评分过滤：跳过评分<5的低质量事件
  - 事件聚类：合并相似事件，减少冗余
  - AI验证：确保锚点准确性

### 🎭 故事框架生成
- 为自定义主角生成个性化故事框架
- 设定主角的背景、性格、目标、起始位置
- 章节规划和事件时间轴
- **动态开场生成**：根据主角档案自动推断来历类型（重生/穿越/原生/未知），生成对应的开场阶段和开场白，避免硬编码
- **智能阶段查找**：优先按章节索引匹配阶段，回退按阶段名匹配，确保角色信息准确传递
- **互动方式设置**：新增"互动方式"参数（低/中/高），与"玩家影响程度"区分使用
  - 玩家影响程度：对剧情结果的改变力度
  - 互动方式：与他人互动的频率与深度
  - **组合效果**：
    - **影响高 + 互动低**：独行改变命运的孤胆英雄
    - **影响低 + 互动高**：融入群体但不改变大局的旁观者
    - **两者都高**：积极干预并社交的主导者
    - **两者都低**：默默无闻的背景角色
    - **影响中 + 互动中**：平衡发展的普通主角
- **智能锚点系统**：AI自动生成原著锚点，支持重要性评分和分层管理
  - 主线锚点（评分9-10）：不可改变的原著关键剧情
  - 重要锚点（评分7-8）：影响剧情走向的重要事件
  - 次要锚点（评分6）：中等重要性事件
  - AI验证机制确保锚点准确性
  - 事件聚类合并相似事件，减少冗余
- 分支点系统允许玩家选择影响故事走向

### 🎮 互动式故事体验
- AI 生成 2-6 个随机选择，每次选择数量不同
- 玩家选择影响故事发展
- 角色状态追踪（境界、位置、存活状态）
- 事件时间轴查看和跳转
- 隐藏经历解锁系统

### 👥 角色管理
- 创建、编辑、删除角色卡
- 导入 TavernAI 格式角色卡
- 角色收藏和搜索
- 角色出现次数统计

### 🌍 世界书系统
- 关键词触发注入
- 全局或按角色绑定
- 支持启用/禁用控制

### 🎯 通用实力等级系统
- 自动适配不同小说的设定
- 支持修炼、等级、战力等不同类型
- 动态生成实力限制规则
- 自动识别原著主角、世界观、禁止概念、细化规则
- 虚构地名识别和地理距离计算

### 🧠 真实性增强功能（已集成到故事生成）
- 角色关系网络分析：识别关系类型、强度量化、一致性检查
- 时间线一致性检查：检测时间矛盾、时间线构建、合理性验证
- 物品/资源追踪：追踪物品获取/使用/失去、使用方法、效果逻辑
- 势力/组织识别：识别势力/组织及其关系
- 实力成长轨迹分析：分析实力提升合理性、检测不合理跳跃
- 地理连续性验证：验证角色移动的地理合理性
- 因果关系分析：分析事件因果关系、检测逻辑漏洞
- 角色性格特征提取：提取性格特征、确保行为一致性
- 设定冲突检测：检测不同设定之间的冲突
- 术语使用一致性：确保术语使用的一致性
- **自动集成**：故事生成时自动调用一致性分析，结果作为AI约束条件

### 🧠 记忆系统
- **短期记忆**：记录最近的选择、物品变化、关系变化（最多20条）
- **长期记忆**：基于语义检索相关记忆，支持记忆压缩和缓存
- **双模式支持**：故事框架模式和普通故事模式均支持记忆系统
- **自动集成**：故事生成时自动检索和注入相关记忆

### 🔄 动态关系系统
- **自动提取**：从AI生成内容中自动提取角色关系变化
- **实时更新**：关系状态随剧情发展自动更新（结盟→敌对等）
- **双模式支持**：故事框架模式和普通故事模式均支持动态关系
- **状态追踪**：维护当前关系状态，支持关系查询和展示

### 🔍 故事测试工具（新增）
- **一键测试**：在Web界面中轻松测试故事质量
- **多项检查**：禁止概念使用、角色设定符合度、剧情合理度、状态一致性
- **可视化报告**：实时显示测试结果和问题列表
- **时间限制**：可设置测试超时时间，防止长时间等待
- **自动推进**：支持自动推进故事模式，随机选择选项进行测试
- **停止功能**：可随时停止正在进行的测试
- **进度保存**：测试状态持久化，页面刷新后继续显示
- **结果删除**：可删除测试结果，重新开始测试
- **通用化设计**：适用于所有小说类型
- **小白友好**：无需命令行操作，界面直观易用

### ⚙️ 灵活配置
- 支持 OpenAI 兼容 API（DeepSeek、Claude 等）
- 多种上下文策略（平衡、极限上下文、极致稳定）
- 预设系统保存和切换模型参数
- 玩家影响程度调节（低/中/高）

## 技术栈

- **前端**: React + Vite + Tailwind CSS
- **后端**: Node.js + Express
- **存储**: 本地 JSON 文件
- **AI API**: OpenAI 兼容接口（支持 DeepSeek）

## 快速开始

### Windows 用户

1. 双击 `启动控制面板.bat`
2. 浏览器自动打开控制面板（http://localhost:3002）
3. 在"小说管理"标签页添加小说文件（只需选择目录，系统自动查找小说文件）
4. 点击"开始提取小说"提取数据
5. 在"配置管理"标签页配置 API Key
6. 在"故事服务"标签页启动服务器
7. 点击"打开故事"开始体验
8. （可选）在侧边栏点击"故事测试"测试故事质量

## 主要特性

### 智能剧情生成
- 基于小说原著的事件和锚点系统
- AI 理解原著设定和角色关系
- 自动生成符合原著风格的故事内容
- 选择差异化，每个选择都有不同的后果方向

### 角色隐藏经历系统
- 随着故事推进逐步揭示角色秘密
- 通过互动、事件、关键词触发解锁
- 分类展示角色的深层背景信息
- 增强故事探索性和沉浸感

### 多主角支持
- 可以为同一小说创建多个不同主角
- 每个主角有独立的框架和故事
- 主角类型支持原创或原著角色
- 自定义主角的详细设定

### 数据持久化
- 所有数据本地存储，保护隐私
- 支持故事存档和恢复
- 角色和世界书可重复使用
- 小说数据只需提取一次

## 快速开始

### 环境配置

1. 复制环境变量模板：
```bash
cp .env.example .env
```

2. 编辑 `.env` 文件，填入你的API密钥：
```env
DEEPSEEK_API_KEY=your_actual_api_key
```

### 启动项目

```bash
# 启动主服务器
cd server
node index.js

# 启动管理面板服务器
node ../panel-server.js
```

### 访问管理面板

打开浏览器访问：http://localhost:3002

详细配置说明请参考 [SETUP.md](SETUP.md)
