# 小说剧情丰富化脚本总览

## 概述

本项目提供了一套完整的小说剧情丰富化工具链，用于从《蛊真人》小说中提取角色、事件、关系等信息，并同步到现有的角色卡系统中。

## 核心脚本

### 1. enrich-story-from-novel.js
**功能**: 完整提取小说所有章节的角色、事件、关系和世界书
- 处理全部 2,698 个章节
- 使用 DeepSeek API 进行智能提取
- 提取角色、事件、关系
- 提取世界书（修行体系、地理势力、蛊虫系统、蛊道杀招、重要概念等）
- 支持断点续传
- 自动保存进度
- **增量提取模式**: 已提取章节只提取世界书，未提取章节完整提取

### 2. verify-story-data.js
**功能**: 验证提取数据的准确性
- 随机抽样验证
- 生成错误报告
- 提供纠错建议
- 支持自动纠错模式

### 3. sync-characters-with-novel.js
**功能**: 同步提取的属性到现有角色卡
- 智能合并角色属性
- 支持别名匹配
- 提供预览模式
- 触发热更新

## 工作流程

```
1. 运行 enrich-story-from-novel.js
   ↓ 生成 data/story_framework.json
   ↓ 生成 data/timeline.json
   ↓ 生成 data/canon_anchors.json
   ↓ 生成 data/character_attributes_cache.json

2. 运行 verify-story-data.js
   ↓ 验证数据准确性
   ↓ 生成 data/correction_suggestions.json

3. 运行 sync-characters-with-novel.js
   ↓ 同步属性到角色卡
   ↓ 触发热更新 API
```

## 前置要求

- **DeepSeek API Key**: 需要设置环境变量 `DEEPSEEK_API_KEY`
- **小说文件**: `Gu Zhen Ren - Gu Zhen Ren.txt` (约 14MB)
- **Node.js**: v14 或更高版本

## 快速开始

```bash
# 1. 设置 API Key
set DEEPSEEK_API_KEY=sk-你的密钥

# 2. 完整提取（预计 1-2 小时）
npm run enrich-story-full

# 3. 验证数据
npm run verify-story

# 4. 同步到角色卡（预览）
npm run sync-characters:dry

# 5. 执行同步
npm run sync-characters
```

## 输出文件

### 提取结果
- `data/story_framework.json` - 故事框架
- `data/timeline.json` - 时间轴
- `data/canon_anchors.json` - 原著锚点
- `data/character_attributes_cache.json` - 角色属性缓存
- `data/worldbook.json` - 世界书（修行体系、地理势力、蛊虫系统、蛊道杀招、重要概念等）

### 验证结果
- `data/correction_suggestions.json` - 纠错建议

### 同步日志
- `logs/character-sync.log` - 同步操作日志

### 临时文件
- `data/extraction_progress.json` - 提取进度（完成后自动删除）

## 注意事项

1. **API 限流**: 脚本已内置 0.8 秒延迟，避免触发速率限制
2. **断点续传**: 中断后重新运行即可从上次保存的位置继续
3. **成本控制**: 2,698 章节预计需要约 2,700 次 API 调用
4. **数据验证**: 务必运行验证脚本检查提取准确性
5. **备份建议**: 同步前建议备份现有角色卡
