# 故障排查指南

## 常见问题及解决方案

### 1. API Key 相关问题

#### 问题: DEEPSEEK_API_KEY 未设置

**错误信息**:
```
❌ 错误: 未设置 DEEPSEEK_API_KEY 环境变量。
   请设置: set DEEPSEEK_API_KEY=sk-你的密钥 (Windows)
   或添加到系统环境变量后重启命令行。
```

**解决方案**:

**Windows**:
```bash
set DEEPSEEK_API_KEY=sk-你的密钥
```

**Linux/Mac**:
```bash
export DEEPSEEK_API_KEY=sk-你的密钥
```

**永久设置**:
- 添加到系统环境变量
- 或在项目根目录创建 `.env` 文件（需要配置 dotenv）

#### 问题: API Key 无效

**错误信息**:
```
❌ 错误: DEEPSEEK_API_KEY 环境变量未设置或为空
```

**解决方案**:
1. 检查 API Key 是否正确
2. 确认 API Key 未过期
3. 检查是否有空格或换行符

---

### 2. 小说文件相关问题

#### 问题: 小说文件不存在

**错误信息**:
```
❌ 小说文件不存在: D:\learn\自建酒馆ai\Gu Zhen Ren - Gu Zhen Ren.txt
```

**解决方案**:
1. 确认小说文件在项目根目录
2. 检查文件路径是否正确
3. 重新下载小说文件

#### 问题: 小说文件过小

**错误信息**:
```
❌ 文件过小 (5.23 MB)，请确保完整小说文件大小约为 14 MB。
   当前文件可能不完整，无法提取全部章节。
```

**解决方案**:
1. 检查文件大小是否约为 14MB
2. 重新下载完整的小说文件
3. 确认下载未中断

#### 问题: 小说文件编码问题

**错误信息**:
```
前 500 字符预览:
乱码乱码乱码...
```

**解决方案**:
1. 确认文件编码为 UTF-8
2. 使用文本编辑器转换编码
3. 重新下载正确编码的文件

---

### 3. API 调用相关问题

#### 问题: 请求超时

**错误信息**:
```
⏱️ 超时，重试 (1/3)...
```

**说明**: 脚本会自动重试，无需干预。

**解决方案**:
1. 检查网络连接
2. 确认 API 服务正常
3. 如持续超时，可增加超时时间

#### 问题: API 速率限制

**错误信息**:
```
429 Too Many Requests
```

**解决方案**:
1. 脚本已内置 0.8 秒延迟，通常不会触发
2. 如仍触发，增加 `REQUEST_DELAY` 参数
3. 等待一段时间后重试

#### 问题: API 配额不足

**错误信息**:
```
402 Payment Required
```

**解决方案**:
1. 检查 API 账户余额
2. 充值或升级套餐
3. 减少处理章节数量

---

### 4. 进度保存相关问题

#### 问题: 进度文件损坏

**错误信息**:
```
进度文件损坏，从头开始
```

**解决方案**:
1. 脚本会自动从头开始
2. 或手动删除进度文件重新开始:
```bash
rm data/extraction_progress.json
```

#### 问题: 无法保存进度

**错误信息**:
```
保存进度失败: EACCES: permission denied
```

**解决方案**:
1. 检查 `data/` 目录权限
2. 确保有写入权限
3. 以管理员权限运行

---

### 5. 验证相关问题

#### 问题: 数据文件未找到

**错误信息**:
```
Error: Story framework file not found. Run enrich-story first.
```

**解决方案**:
1. 先运行 `npm run enrich-story-full` 完成数据提取
2. 确认输出文件已生成
3. 检查文件路径是否正确

#### 问题: 验证准确率低

**错误信息**:
```
Characters found in novel: 15 (60%)
```

**可能原因**:
- 提取质量不高
- 角色名不准确
- 小说版本不同

**解决方案**:
1. 检查提取日志
2. 手动审核错误报告
3. 调整抽样大小
4. 重新提取数据

---

### 6. 同步相关问题

#### 问题: 角色卡目录未找到

**错误信息**:
```
Error: Characters directory not found
```

**解决方案**:
1. 确认 `characters/` 目录存在
2. 创建目录:
```bash
mkdir characters
```

#### 问题: 属性缓存文件未找到

**错误信息**:
```
Error: Character cache file not found. Run enrich-story first.
```

**解决方案**:
1. 先运行 `npm run enrich-story-full` 完成数据提取
2. 确认 `data/character_attributes_cache.json` 已生成

#### 问题: 热更新失败

**错误信息**:
```
Hot update failed (API might not be running): connect ECONNREFUSED
```

**说明**: 这不影响角色卡同步，仅影响故事引擎的热更新。

**解决方案**:
1. 确保服务器正在运行
2. 检查 API 端点是否正确
3. 或忽略此错误，手动重启服务器

---

### 7. 内存相关问题

#### 问题: 内存不足

**错误信息**:
```
JavaScript heap out of memory
```

**解决方案**:
1. 增加 Node.js 内存限制:
```bash
node --max-old-space-size=4096 server/enrich-story-from-novel.js
```
2. 减少处理章节数量
3. 关闭其他占用内存的程序

---

### 8. 网络相关问题

#### 问题: 网络连接失败

**错误信息**:
```
getaddrinfo ENOTFOUND api.deepseek.com
```

**解决方案**:
1. 检查网络连接
2. 确认 DNS 解析正常
3. 检查防火墙设置
4. 尝试使用代理

#### 问题: SSL 证书错误

**错误信息**:
```
UNABLE_TO_VERIFY_LEAF_SIGNATURE
```

**解决方案**:
1. 更新 Node.js 版本
2. 或禁用 SSL 验证（不推荐）:
```javascript
process.env.NODE_TLS_REJECT_UNAUTHORIZED = '0';
```

## 性能优化

### 1. 减少处理时间

**调整请求延迟**:
```javascript
const REQUEST_DELAY = 500; // 减少到 0.5 秒
```

**注意**: 可能触发 API 速率限制。

### 2. 减少内存占用

**减少处理章节数量**:
```javascript
const MAX_CHAPTERS = 1000; // 只处理前 1000 章
```

### 3. 并行处理（高级）

可以修改脚本支持并行处理章节，但需要确保不超过 API 速率限制。

## 预防措施

### 1. 定期备份

```bash
# 备份角色卡
cp -r characters characters.backup

# 备份数据文件
cp -r data data.backup
```

### 2. 使用预览模式

```bash
# 预览同步
npm run sync-characters:dry
```

### 3. 监控运行状态

```bash
# 后台运行并记录日志
nohup npm run enrich-story-full > extraction.log 2>&1 &

# 监控日志
tail -f extraction.log
```

### 4. 分步执行

不要一次性执行所有操作，分步验证每一步的结果。
