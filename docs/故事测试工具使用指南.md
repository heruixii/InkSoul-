# 故事测试工具使用指南

## 简介

故事测试工具是一个自动化的故事质量检测系统，可以帮你检查故事与原作设定的符合度、角色设定的一致性以及剧情的合理度。

## 功能特点

### 一键测试
- 在Web界面中轻松测试故事质量
- 无需命令行操作，界面直观易用
- 支持批量测试多个故事

### 多项检查
- **禁止概念使用测试**：检查故事内容是否使用了小说禁止的概念术语
- **角色设定符合度测试**：检查角色行为是否符合其设定
- **剧情合理度测试**：检查剧情是否符合世界观合理性规则
- **状态一致性测试**：检查物品、关系等状态是否保持一致

### 可视化报告
- 实时显示测试结果
- 详细的问题列表和修复建议
- 总体评分和各项测试得分

### 时间限制
- 可设置测试超时时间（秒）
- 防止长时间等待
- 超时后自动中断并生成报告

### 自动推进
- 支持自动推进故事模式
- 随机选择选项进行测试
- 适用于长时间自动化测试
- 可配合时间限制使用

### 停止功能
- 可随时停止正在进行的测试
- 立即中断测试并显示当前状态
- 防止测试卡住或耗时过长

### 进度保存
- 测试状态持久化到本地存储
- 页面刷新后继续显示测试状态
- 防止意外丢失测试进度

### 结果管理
- 可删除测试结果
- 清除本地存储的测试数据
- 重新开始新的测试

### 通用化设计
- 适用于所有小说类型
- 自动识别小说配置
- 无需手动设置

## 使用方法

### 方法一：通过Web界面使用（推荐）

1. 启动服务器并打开Web界面
2. 在左侧侧边栏点击"故事测试"
3. 选择要测试的故事（支持多选）
4. 可选：设置时间限制（输入秒数，0表示无限制）
5. 可选：勾选"自动推进故事"启用自动推进模式
6. 点击"运行测试"按钮
7. 测试过程中可点击"停止测试"按钮中断测试
8. 查看测试结果报告
9. 可点击"删除结果"按钮清除测试数据

### 方法二：通过命令行使用

#### 测试所有故事
```bash
cd server
node story-tester.js
```

#### 交互式模式
```bash
cd server
node story-tester.js -i
```

在交互式模式下：
1. 选择要测试的故事（输入序号或'all'）
2. 设置时间限制（输入秒数，0或留空表示无限制）
3. 查看测试结果

#### 查看帮助
```bash
cd server
node story-tester.js --help
```

## 测试结果解读

### 总体评分
- **80分以上**：故事质量良好
- **60-79分**：故事质量一般，存在一些问题
- **60分以下**：故事质量较差，需要修复

### 各项测试结果

#### 禁止概念使用测试
- **通过**：故事中没有使用禁止的术语
- **失败**：故事中使用了禁止的术语，会在问题列表中显示具体术语和建议替代

#### 角色设定符合度测试
- **通过**：角色行为符合其设定
- **失败**：角色背景验证失败，会在问题列表中显示具体错误

#### 剧情合理度测试
- **通过**：剧情符合世界观合理性规则
- **失败**：存在不合理的地方，会在问题列表中显示具体问题

#### 状态一致性测试
- **通过**：物品、关系等状态保持一致
- **失败**：存在状态不一致的问题，会在问题列表中显示具体问题

## 常见问题

### Q: 为什么有些测试被跳过？
A: 如果小说没有配置相应的规则（如禁止概念、角色验证规则等），相关测试会被跳过。这是正常的，不会影响其他测试的进行。

### Q: 测试需要多长时间？
A: 测试时间取决于故事的数量和长度。一般情况下，单个故事的测试时间在几秒到几十秒之间。你可以设置时间限制来防止长时间等待。

### Q: 如何修复测试发现的问题？
A: 测试报告会提供详细的问题描述和修复建议。根据建议修改故事内容或小说配置即可。

### Q: 测试结果会保存吗？
A: 每次测试都会生成一份JSON格式的报告，保存在 `server/story-test-report.json`。你可以查看历史测试结果。

## 高级功能

### 自定义测试规则

你可以在小说的元数据配置文件中自定义测试规则：

```json
{
  "forbiddenConcepts": {
    "currency": {
      "primary": "元石",
      "forbidden": [
        { "term": "铜钱", "reason": "本小说使用元石", "alternative": "元石" }
      ]
    }
  },
  "characterValidationRules": {
    "originalCharacter": {
      "forbiddenBackgroundPatterns": ["重生", "夺舍"],
      "requiredElements": ["穿越"]
    }
  }
}
```

### 批量测试

在Web界面中，你可以：
- 点击"全选"复选框选择所有故事
- 手动选择多个故事进行测试
- 设置时间限制来控制测试时长

## 注意事项

1. 测试工具是基于规则的自动化检测，可能无法发现所有问题
2. 测试结果仅供参考，人工审核仍然重要
3. 定期运行测试可以及时发现和修复问题
4. 测试过程中请勿关闭浏览器或刷新页面
